# AI 60 秒信息播报结构研究

- 研究角色：Codex
- 研究日期：2026-08-01
- 交付：T105；供 Grok 审查后落成 `AiNews60sReport`、prompt、质量门禁和页面组件

## 可核验观察

口罩哥的 Bilibili 系列页显示该栏目以“口罩哥研报60秒”为统一系列名，页面列出约 95 个视频；可见样本标题通常只聚焦一个事件或判断对象，例如折叠屏、能源制裁、OPEC 产能、AI OCR、黄金与央行政策等。[系列页](https://www.bilibili.com/list/3632315498498795?bvid=BV1PrXaBFECB&oid=116318250471554)（访问：2026-08-01）

这些页面元数据只能支持“栏目命名、单议题、高密度标题和市场/产业关联”的结构观察，不能支持复制具体脚本、语音、节奏、表情或个人观点。项目实现采用原创编辑模板。

## 抽象出的编辑结构

| 时间预算 | 交付内容 | 必须回答 |
| --- | --- | --- |
| 0–3 秒 | 一句话钩子 | 今天发生了什么？ |
| 3–12 秒 | 事实核 | 谁在何时发布了什么？原始来源是什么？ |
| 12–30 秒 | 机制解释 | 为什么重要？影响链条经过哪些环节？ |
| 30–45 秒 | 产业/市场映射 | 哪些行业或公司可能暴露于该变化？只描述传导，不给买卖指令。 |
| 45–54 秒 | 反证与风险 | 哪个假设可能错？还有什么信息未确认？ |
| 54–60 秒 | 来源与免责声明 | 数据截止时间、运行 ID、引用和“研究/模拟，非投资建议”。 |

## 生产门禁

1. 一期只允许一个主议题，最多五条事实 bullet；每条都有 citation。
2. 发生时间、发布时间、抓取时间分开保存；没有日期不能进入“最新”栏。
3. 标题可口语化，但事实、数字、公司名和政策名必须保持原义并转义输出。
4. “相关公司/赛道”只描述可能的暴露路径，不给目标价、收益承诺或交易指令。
5. 单源内容标为“待交叉验证”；官方来源、原始论文、监管文件优先。
6. 60 秒版本是摘要，不删除长版证据、反证、数据截止时间和来源。

```json
  "risks_and_counterpoints": [{"text": "反证", "label": "counterpoint", "uncertainty": "medium", "citations": ["evidence-id"]}],
  "citations": [{"url": "https://example.com/source", "title": "原始来源", "fetched_at": "..."}],
  "run_id": "...",
  "disclaimer": "仅供研究与模拟，不构成投资建议。"
}
```

## 不能做的事

- 不能生成“口罩哥本人播报”、复刻其声音/头像/固定口头禅或改写其原文。
- 不能把 Bilibili 标题本身当作事实来源；必须回到原始公告、论文、监管文件或数据集。
- 不能用栏目名称暗示任何创作者授权、合作或背书。
