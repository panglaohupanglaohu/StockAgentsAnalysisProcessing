## 抽象出的分析结构

```text
发生了什么
→ 时间线：事件、前因、转折、当前状态
→ 关键驱动：制度、技术、资本、资源、人口、联盟
→ 数据验证：指标、单位、区间、基准、变点
→ 因果链：驱动 → 中间变量 → 行业/区域传导
→ 主要解释与反证：至少一个替代解释
→ 情景树：乐观 / 基准 / 悲观 + 触发条件
→ 可能的市场暴露路径：行业/公司类别，不是荐股
→ 来源、截止时间、置信度与免责声明
```

## 生产门禁

1. 每个结论标注 `fact`、`analysis`、`inference`、`opinion` 或 `scenario`。
2. 历史类比必须给出相似条件与不相似条件，不能把类比写成预测。
3. 数据分析员输出清洗规则、缺失值处理、时间频率、样本范围和单位。
4. Red Team 至少提出一个反证或替代解释，并记录未解决争议。
5. 地缘政治/政策来源必须同时记录发布机构、地区、语言、立场/利益相关性和访问限制。
6. 市场传导只描述路径和敏感变量；不得写成买入、卖出、目标价或确定收益。
