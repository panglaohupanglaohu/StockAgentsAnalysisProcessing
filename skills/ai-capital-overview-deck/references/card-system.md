# 20-card research deck grammar

Each card must have a title, data cutoff, source/sample label, chart legend or text alternative, and a clear distinction between observed facts and research proxies.

| Card | Purpose | Data / visual grammar |
|---|---|---|
| 01 Cover | Name the run and main thesis | Headline, cutoff, source count, strongest theme |
| 02 Editorial note | State why the run matters | 3 thesis claims + uncertainty |
| 03 Contents / method | Show the evidence contract | pipeline stages, scope, source rules |
| 04 Landscape | Show attention by topic | topic distribution bars |
| 05 Evidence pulse | Show volume and freshness | time-series bars, source counts |
| 06 Comparative signal | Compare leading themes | ranked comparative bars |
| 07 Confidence bubble | Separate signal from confidence | score vs freshness / novelty scatter proxy |
| 08 Source-mix donut | Show evidence quality mix | high / medium / low score donut |
| 09 Top-three comparison | Compare strongest themes | 3-column metric comparison |
| 10 Source ranking | Identify leading sources | top hosts by count and mean score |
| 11 Dual track | Separate domestic / international domain proxies | two-track ratio with proxy label |
| 12 Long tail | Show diversity beyond the leaders | second-tier source list |
| 13 Focal signal | Detail the strongest observed signal | top title, score, citations |
| 14 Flow map | Show event to business path | topic → impact Sankey-like links |
| 15 Pareto | Show concentration | cumulative topic shares |
| 16 Evidence hub | Show relationships | source / topic / impact network |
| 17 Uncertainty | Preserve gaps and counterevidence | uncertainty rings + open questions |
| 18 Adoption-cost proxy | Show mechanism hypothesis | cost / adoption / revenue proxy curve, explicitly labeled |
| 19 Four risks | Place risks by impact and confidence | 2×2 risk matrix |
| 20 Closing | Summarize actions and watch items | six takeaways, citations, disclaimer |
